An example is a little argument

Code
Writing
A few lines of code can do the work of a long explanation.
Published

October 12, 2026

A useful example is small enough to hold in mind and complete enough to run. It gives the reader something concrete to question, change, and understand.

Start small

def twice(value):
    return value + value

assert twice(21) == 42

The explanation can grow from here, one decision at a time.
