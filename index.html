A small library, thoughtfully built

On keeping good ideas close, and giving them room to breathe.

Good documentation feels like a well-kept notebook. There is a clear place to begin, enough space to think, and a useful example just when you need one. The page makes room for the work.

Begin with a simple idea

Imagine a little library of things you want to return to: an essay, a useful function, a question that deserves a second look. Each entry needs a title, a few words of context, and a way to find it again.

library.py
from dataclasses import dataclass

@dataclass
class Entry:
    title: str
    tags: tuple[str, ...] = ()

library = [Entry("The art of paying attention", ("reading",))]

The code uses IBM Plex Mono, with a little more room between lines. Names, punctuation, and indentation stay distinct. Inline expressions such as entry.title belong comfortably in the surrounding text.

Leave room for the reader

A useful page has a rhythm: a thought, an example, a pause. Headings mark a change of subject. A quieter margin keeps the route through the document visible without competing for attention.[1]

A good notebook is a place to think on paper, and a place to find that thought again.
